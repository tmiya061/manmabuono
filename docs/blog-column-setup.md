# コラム（ブログ）セットアップ手順

テーマ側の実装（`templates/article.column.json` / `sections/c_article.liquid`）が参照する
メタオブジェクト・メタフィールドを Shopify 管理画面で作成する手順。
**キー名はコードと一致させる必要があるため、この通りに入力すること。**

---

## 1. ブログ本体の作成

1. 管理画面 > オンラインストア > ブログ記事 > **ブログを管理** > ブログを追加
2. タイトル：`コラム`（任意の表示名でOK）
3. **ハンドル：`column`**（URL が `/blogs/column` になる。ここは必ず `column`）
4. コメント：無効を推奨

## 2. メタオブジェクト定義①：著者・監修者

設定 > カスタムデータ > メタオブジェクト > 定義を追加

- 名前：`記事著者`
- **タイプ（ハンドル）：`article_author`**

| フィールド名 | キー | タイプ |
|---|---|---|
| 名前 | `name` | 1行テキスト |
| 肩書き | `role_title` | 1行テキスト |
| 顔写真 | `photo` | ファイル（画像） |
| 保有資格 | `qualification` | 1行テキスト（例：獣医師） |
| プロフィール | `bio` | 複数行テキスト |
| プロフィールページURL | `profile_url` | URL（2026-08-17 追加） |
| SNS・外部プロフィール | `same_as` | URLのリスト（2026-08-17 追加） |

> `profile_url` / `same_as` は E-E-A-T 用で、構造化データの `Person.url` / `Person.sameAs` に出力される（著者カードの見た目には出ない）。
> キーを `url` にしていないのは、メタオブジェクトのドロップが持つ組み込みプロパティと衝突させないため。

> **重要**：定義の「オプション」で **ストアフロントへのアクセスを有効化** にチェックを入れること（入れないとテーマから読めない）。

作成後、「コンテンツを追加」から実際の著者（例：マンマボーノ編集部、監修の獣医師）を登録する。

## 3. メタオブジェクト定義②：記事カテゴリ

- 名前：`記事カテゴリ`
- **タイプ（ハンドル）：`article_category`**
- こちらも **ストアフロントへのアクセスを有効化**

| フィールド名 | キー | タイプ |
|---|---|---|
| 表示名 | `name` | 1行テキスト |
| 説明文 | `description` | 複数行テキスト |

### 登録するエントリー（7カテゴリ）

**各エントリーの「ハンドル」を下記スラッグに手動で変更すること**（ハンドル＝タグ＝URLになる）。

| ハンドル（＝記事に付けるタグ） | 表示名 | 説明文の例 |
|---|---|---|
| `choose` | 選び方・おすすめ | 愛犬・愛猫に合ったフードの選び方、おすすめ商品の比較情報 |
| `trouble` | 食べない・好き嫌い | ごはんを食べない、好き嫌いが激しいときの原因と対処法 |
| `feeding` | 与え方・食事管理 | 適切な給餌量、ふやかし方、ドライとウェットの併用方法など |
| `health` | 健康・症状別ケア | 腎臓・尿路・便秘など、症状や体調に合わせた食事のポイント |
| `storage` | 保存・容器 | フードの正しい保存方法と容器選び、鮮度を保つコツ |
| `basics` | 基礎知識 | ペットフードの種類や表示の見方、安全法などの基礎知識 |
| `homemade` | 手作り・レシピ | 手作りごはんの基本と、安心して作れるレシピ |

## 4. 記事メタフィールドの定義

設定 > カスタムデータ > **ブログ記事** > 定義を追加（ネームスペースとキーは下記の通り）

| 名前 | ネームスペースとキー | タイプ | 参照先 |
|---|---|---|---|
| 著者 | `custom.author` | メタオブジェクト参照 | 記事著者（1件） |
| 監修者 | `custom.supervisor` | メタオブジェクト参照 | 記事著者（1件） |
| 関連コレクション | `custom.related_collection` | コレクション参照 | （1件）記事下CTAの「もっと見る」先 |
| おすすめ商品 | `custom.related_products` | 商品参照 | **リスト（複数可）**。記事下CTAに商品カードで最大3件表示 |

## 3-2. メタオブジェクト定義③：おすすめ商品セット【定義済み・API連携で運用】

- 名前：`おすすめ商品セット` / タイプ：`product_recommendation`（**作成済み**）
- フィールド：商品（`product`・商品参照）＋ 訴求文（`copy`・1行テキスト・**任意**）
- 記事メタフィールド `custom.recommendations`（メタオブジェクト参照・リスト）も**作成済み**

**運用（都度指定方式）**：記事が完成したら、その記事に載せる商品と（必要なら）一言をClaudeに指定 →
`scripts/set_article_cta.py` がエントリー作成〜記事への紐付けまで自動で行う。管理画面での手作業は不要。

```
python3 scripts/set_article_cta.py <記事handle> "<商品handle>" "<商品handle>::<一言>" ...
```

- 訴求文は任意。**基本はなし**（商品名＋価格のカードのみ）で、書きたい記事だけ `::` の後ろに付ける
- 再実行で丸ごと置き換え。`--clear` で全解除
- 表示の優先順位：`custom.recommendations`（セット）→ `custom.related_products`（商品のみ）→ 関連コレクションのカード

## 5. テンプレートの割り当て

記事作成画面の右下「テーマテンプレート」で **`column`** を選択する。
（コラムの全記事で `article.column` を選ぶ。デフォルトのままだと旧デザインになる）

# 記事の書き方ルール

## タグの付け方

- **カテゴリタグを必ず1つだけ**付ける（上の7スラッグのどれか。例：`trouble`）
  - 2つ以上付けると最初に一致したものがカテゴリ扱いになるので付けない
- 必要に応じて**自由タグ**を付ける（複数OK）：
  - 動物：`cat`（猫）/ `dog`（犬）
  - ライフステージ：`kitten`（子猫）/ `puppy`（子犬）/ `senior`（シニア）
  - フード種別：`dry` / `wet`
  - 日本語ラベルは `snippets/c_tag-label.liquid` で管理（タグを増やしたらここに追記）
- **タグは必ず半角英字で**。日本語タグはURLが文字化けするので使わない

## 各項目

- **アイキャッチ**：記事の「画像」に設定（16:9 推奨、横1200px以上）
- **抜粋（excerpt）**：一覧カードと検索結果の説明文に使うので必ず書く（80字前後）
- **著者・監修者**：記事編集画面下部のメタフィールドで選択。未設定時は「マンマボーノ編集部」表示
- **おすすめ商品**：記事完成後にClaudeへ「この記事に◯◯と◯◯を載せて」と依頼（scripts/set_article_cta.py で反映。一言テキストは任意）
- **関連コレクション**：商品を設定しない記事のフォールバック用（コレクションカードが出る）。任意
- 見出しは **H2 → H3** の順で使う（目次はH2/H3から自動生成される）

## 記事内に貼れるHTMLパーツ

記事エディタの `<>`（HTMLを表示）モードで貼り付ける。

### ポイントボックス

```html
<div class="ca-box">
<p class="ca-box__title">ポイント</p>
<p>ここに本文を書く</p>
</div>
```

### 注意ボックス

```html
<div class="ca-box --warn">
<p class="ca-box__title">注意</p>
<p>ここに本文を書く</p>
</div>
```

### メモボックス

```html
<div class="ca-box --memo">
<p class="ca-box__title">メモ</p>
<p>ここに本文を書く</p>
</div>
```

### 吹き出し（画像URLは「コンテンツ > ファイル」にアップしてURLをコピー）

```html
<div class="ca-balloon">
<div class="ca-balloon__icon"><img src="画像URL" alt="編集部"></div>
<p class="ca-balloon__text">セリフをここに書く</p>
</div>
```

### CTAボタン

```html
<a class="ca-btn" href="/collections/コレクションのハンドル">おすすめフードを見てみる</a>
```

# 実装メモ（開発者向け）

- カテゴリ判定：`article_category` メタオブジェクトの**ハンドルと一致するタグ**をカテゴリとみなす（prefix運用なし）
- カテゴリページURL：`/blogs/column/tagged/<slug>`（Shopify標準のタグ絞り込み）
- 関連記事：`blog.articles`（最新50件）から同カテゴリタグを持つ記事を最大3件表示
- パンくず：`snippets/c_bredcrumb.liquid` が `blog.handle == 'column'` のときだけカテゴリ階層を挟む
- 構造化データ：Article（author / reviewedBy / articleSection）+ BreadcrumbList を `c_article.liquid` が出力
- SCSSは `assets/c_article.scss` を編集 → Live Sass Compile または `sass --style=compressed --no-source-map assets/c_article.scss assets/c_article.min.css`
