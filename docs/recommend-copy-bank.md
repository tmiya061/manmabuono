# 訴求文バンク（おすすめ商品セット登録用）

コラム記事の「この記事を読んだ方におすすめ」に使う **商品×訴求文** の一覧。

## 使い方

1. **商品側のデフォルトキャッチ**（下の①）→ 各商品のメタフィールド `custom.recommend_copy` にコピペ（1回だけ）
2. **記事文脈別の訴求文**（下の②）→ メタオブジェクト「おすすめ商品セット」（`product_recommendation`）のエントリーとして登録し、記事から選択
3. 表現ルール：効能の断定（治る・予防できる）は使わない。「〜な子に」「〜をサポート」「〜と言われる」まで

## 運用メモ

- **マスターは scripts/copy_bank_setup.py**（このMarkdownはその写し）
- 訴求文の追加・変更 → スクリプトの RECOMMENDATIONS を編集 → `python3 scripts/copy_bank_setup.py` 実行（冪等・全件upsert）
- Claudeに「◯◯の切り口の訴求文を足して」と頼めば、スクリプト更新→実行→このドキュメント同期まで一括で対応
- 記事側では、記事編集画面のメタフィールド「おすすめ商品セット」からエントリーを2〜3個選ぶだけ
